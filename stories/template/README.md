# 钱塘里·樱花大道的手机

基于作者提供的越剧《钱塘里》梗概改编。陆亚飞仍为美乙团高管；六城巡演是面向玩家的戏外宣传彩蛋，不是角色的工作行程。具体日期及手机文案为改编补写，场次按作者提供的信息录入。

## 夏季时间线

- 7月1日雨夜：方小米撞伤金月芳，离开医院后回来承担责任。
- 7月2日：方小米借钱，陆亚飞通过支付宝转账8万元。
- 7—8月：照护与日常相处。7月3日S1项目暂停，原定7月9—10日广州会议取消。
- 8月5—6日：妈妈喊亚飞回家吃饭、小米询问回家时间的微信互动。
- 8月18日：身份暴露、项目正式终止、亚飞提出辞职，随后江边相遇。

锁屏、状态栏显示实时北京时间；历史记录保留剧情日期。私人备忘录密码与原定广州出发日期一致，为0709。

## 游玩与宣传彩蛋

阅读照护交接及钱包垫付记录，解锁雨夜经过；再读广州行程和项目邮件，解锁私人备忘录。模拟来电接听后挂断或拒接均可继续。可以直接归还手机，也可以先读日记。

读完方小米日记，解锁备忘录「戏外彩蛋｜《钱塘里》六城巡演」。选择「先查看六城巡演彩蛋」后，依次在日历中查看11月1日西安、11月8日无锡、11月15日济南、11月22日南昌、11月29日广州、12月6日福州的演出详情。每站解锁一条已点亮记录，集齐六站解锁「六城已点亮｜剧场见」。阅读邀请后可归还手机。提前看过日历也会被计入。

微信的两段吃饭对白可逐条点击展开。其余聊天由作者继续补写。抖音、小红书内嵌演员公开主页，内容加载取决于平台网络与登录要求；支付宝为剧情账单，不执行真实转账。

## 编辑与验证

编辑story.json；运行npm run dev可实时预览，验证失败时保留上一份有效版本。变更剧情时增加revision，重启旧游玩进度。运行npm run story:validate、npm run story:test和npm run build。脚本含10条通关路径；浏览器验证使用stories/template/qa/playwright.config.ts。
